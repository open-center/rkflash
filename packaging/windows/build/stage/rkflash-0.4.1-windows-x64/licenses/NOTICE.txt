RKFlash · RK 固件烧录（Windows 版）
https://github.com/open-center/rkflash

本软件由多个独立组件组成，分别按以下许可证发布（完整文本位于安装目录 licenses\）：

  rkflash.exe        RKFlash 图形界面与后端              MIT
  rkdeveloptool.exe  Rockchip rkdeveloptool（含修改）    GPL-2.0-or-later
                     内置 libusb 1.0.30                   LGPL-2.1-or-later
  driver\wdi-simple.exe  libwdi 1.5.1 驱动安装工具        LGPL-3.0-or-later
                     内嵌 Microsoft WDK 8.0 WinUSB/KMDF   见 WDK-Redist-License.rtf
                     再分发组件（仅 Windows 7 使用）

rkdeveloptool、libusb 与 libwdi 的对应源码可从上述仓库获取
（native/ 目录与 windows/driver/build.sh 中固定版本的上游源码）。

USB 驱动说明：
  安装程序会为 Rockchip 设备（USB VID 2207）安装 Windows 自带的 WinUSB 驱动。
  这会替换 Rockchip 官方驱动（DriverAssitant）。如需继续使用 RKDevTool，
  请重新运行官方驱动安装程序。

本软件按“原样”提供，不附带任何明示或暗示的担保。烧录操作可能导致设备数据丢失，
请确认固件与目标芯片匹配，并保持 USB 与电源稳定。
