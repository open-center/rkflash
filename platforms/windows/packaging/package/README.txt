RKFlash · RK 固件烧录（Windows 免安装版）

使用步骤：
  1. 首次使用先双击 install-driver.cmd，在弹出的管理员确认中选择“是”，
     为 Rockchip 设备安装 WinUSB 驱动（只需一次）。
  2. 开发板进入 Loader 或 Maskrom 模式后用 USB 连接电脑。
  3. 双击 rkflash.exe 启动。

文件说明：
  rkflash.exe          图形界面
  rkdeveloptool.exe    烧录核心（也可在命令行单独使用）
  driver\              WinUSB 驱动安装工具
  licenses\            第三方许可证

支持 64 位 Windows 10/11。项目主页：https://github.com/open-center/rkflash
