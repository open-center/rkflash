# App Review 备注草案

本应用不需要登录，也不连接开发者服务器。核心功能需要通过 USB 连接 Rockchip 开发板；
应用使用 `com.apple.security.device.usb` 权限，并通过继承主应用沙盒的内置辅助工具执行协议通信。

审核建议步骤：

1. 使用支持 Rockchip USB 下载协议的开发板进入 Maskrom 或 Loader 模式。
2. 启动应用，底部会显示设备模式、VID、PID 和位置。
3. 选择与硬件匹配的 RKFW/RKAF 固件，核对解析出的芯片、Loader、MD5 和分区。
4. 执行升级并观察 Loader 切换、分区写入、进度、校验和最终重启。

提交时请附上 15–30 秒实体设备演示视频，以及测试板型号、进入 Maskrom/Loader 的按键步骤、
测试固件下载地址和 SHA-256。若固件不能公开，请在审核附件中提供，并保证审核期间持续可用。
